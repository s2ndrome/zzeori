# 케이브덕 한글 스킨 (Chrome 확장)

caveduck.io 채팅 화면(`/talk/...`)을 한컴오피스 **한글** 편집 창처럼 보이게 바꾸는 크롬 확장(Manifest V3)입니다.
채팅 기능(스크롤, 입력, 전송, 재생성·수정 버튼, 메뉴, 모달)은 원래대로 동작합니다. 외부 네트워크 요청이나 추적 코드는 없고, 권한은 `storage` 하나뿐입니다.

## 설치

1. 이 `hangul-skin` 폴더를 내 컴퓨터에 받아 둡니다. (저장소를 받거나 ZIP으로 내려받아 압축 해제)
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `hangul-skin` 폴더(안에 `manifest.json`이 있는 폴더)를 고릅니다.
5. 케이브덕 채팅 화면을 새로고침합니다.
6. 주소창 오른쪽 퍼즐 아이콘 → **케이브덕 한글 스킨** 핀 고정 → 아이콘을 누르면 설정 팝업이 열립니다.

코드를 고친 뒤에는 `chrome://extensions`에서 확장의 새로고침(↻) 버튼을 누르고 케이브덕 탭도 새로고침하세요.

> 노션 스킨 등 비슷한 스킨 확장과 동시에 켜면 서로 덮어쓰니, 하나만 켜 두세요.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 제목 표시줄 | `{캐릭터}.hwp - 한글`, 빠른 실행 아이콘, 최소화/최대화/닫기 (장식) |
| 메뉴 탭 | 파일 · 편집 · 보기 · 입력 · **서식** · 쪽 · 보안 · 검토 · 도구 (장식). 오른쪽 끝의 `<` `⚙`는 케이브덕 원래 **뒤로/설정 버튼**이라 그대로 동작 |
| 리본 / 서식 도구 상자 | 대부분 장식. **글자 크기(콤보·▲▼)와 줄 간격(콤보·▲▼)은 실제로 동작**하고 설정에 저장 |
| 가로 눈금자 | 용지 위치에 맞춰 mm 눈금, 본문 폭(150mm)은 흰 구간 |
| 편집 영역 | 회색 바탕 위 A4 용지(794px = 210mm, 좌우 여백 30mm). 1123px(297mm)마다 점선 쪽 구분선과 편집 용지 모서리 표시 |
| 문서 제목 | 맨 위 안내문 자리에 캐릭터 이름(크게) + `작성일: YYYY. MM. DD.` |
| 본문 | 프리텐다드 (케이브덕이 이미 불러오는 Pretendard를 그대로 사용, 추가 웹폰트 요청 없음). 나레이션·대사 모두 검정, 이탤릭 제거 |
| 내 메시지 | 기본 `메모 N` 노란 상자 (번호 자동) |
| 상태창·HTML 카드 | 기본 `▸ [표 N] 상태창` / `▸ [표 N] 글상자` 캡션 한 줄. 누르면 펼치고, 캡션을 다시 누르면 접힘 |
| 메시지 버튼줄 | 평소 숨김, 메시지에 마우스를 올리면 오른쪽 여백·아래에 작은 회색 아이콘 (마지막 메시지 아래 줄은 흐리게 항상 표시) |
| 입력창 | 용지 맨 아래 다음 문단처럼. 비어 있으면 깜빡이는 커서 + `내용을 입력하세요`. 버튼은 회색 아이콘 한 줄 |
| 문서 탭 | 왼쪽 메뉴의 최근 대화를 `{이름}.hwp` 탭으로. 누르면 원래 링크를 눌러 이동 |
| 상태 표시줄 | `현재쪽/전체쪽` · 줄/칸(입력창 커서 위치) · 글자 수 · 문단 수 · 확대 슬라이더(실제 확대) |
| 탭 제목·파비콘 | `{캐릭터}.hwp - 한글`, 직접 그린 파란 문서 아이콘 (끄면 원래 제목·파비콘 복원) |
| 보스 키 | **Alt+Q**: 「2026년 하반기 주요 업무 추진 계획(안)」 가짜 문서 화면을 덮었다 걷기 |
| 좁은 화면(<768px) | 제목줄 + 용지 + 상태 표시줄만 |

## 팝업 설정

- 스킨 켜기/끄기, 보스 키 사용
- 내 메시지: 메모 / 본문(회색 음영) / 본문(왼쪽 세로선) / 숨김
- 상태창·HTML 카드: 접기 / 흑백 / 보이기 / 숨김
- 캐릭터 이미지: 숨김 / 작게 (문서 제목 아래 흑백 그림)
- 대사 살짝 굵게, 문단 첫 줄 들여쓰기
- 글자 크기(pt), 줄 간격(%), 쪽 확대(%) — 리본·상태 표시줄과 같은 값
- 왼쪽 메뉴: 숨김(문서 탭 사용) / 보이기
- 파일 이름 형식 (기본 `{캐릭터}.hwp`)

설정은 `chrome.storage.local`(`hwpSkin`)과 케이브덕 `localStorage`(`hwpSkin`)에 같이 저장됩니다. localStorage 덕분에 페이지를 열자마자(`document_start`) 설정을 읽어 원래 화면이 깜빡이지 않습니다.

## 구조

```
hangul-skin/
├─ manifest.json   MV3, content_scripts(document_start), 권한 storage
├─ content.js      페이지 판별·설정 동기화·한글 UI 요소(#hwp-*) 붙이기·상태 표시줄 계산·보스 키
├─ theme.css       모든 규칙이 html[data-hwp-theme] 아래 (채팅 화면은 [data-hwp-page="talk"])
├─ popup.html/js   설정 팝업
├─ icons/          확장 아이콘 (직접 그린 SVG → PNG)
└─ test/           테스트 도구 (확장 동작에는 필요 없음)
```

원칙
- `<html>`에 `data-hwp-theme`, `data-hwp-page`, `data-hwp-memo` 같은 속성과 `--hwp-*` CSS 변수만 붙이고, 끄면 모두 지웁니다.
- React가 관리하는 노드는 지우거나 옮기지 않습니다. CSS(`position`, `display`, `::before/::after`, `counter`)로만 바꾸고, 새 UI(`#hwp-top`, `#hwp-bottom`, `#hwp-boss`)는 body에 따로 붙입니다. React 재렌더링으로 사라지면 `MutationObserver`(250ms 스로틀)와 1초 `setInterval`이 다시 붙입니다.
- 카드 펼침 상태는 카드 요소의 `data-hwp-open` 속성 하나로 처리합니다.
- 글자 수·문단 수는 700ms 디바운스로 계산합니다. 쪽 계산은 역방향 스크롤(`flex-col-reverse`)이라 `scrollTop` 대신 화면상 위치(`getBoundingClientRect`)를 씁니다.

### 사용한 셀렉터

| 부분 | 셀렉터 |
|---|---|
| 캐릭터 이름 | `main header nav > button.truncate` (없으면 최근 대화 목록의 현재 대화 `aria-label`) |
| 설정/뒤로 버튼 | `main header` 전체를 메뉴 줄 오른쪽에 고정 |
| 왼쪽 메뉴 | `body > div.flex > div:has(> nav.w-64)`, 최근 대화 `nav.w-64 ul li a[href*="/talk/"]` |
| 스크롤 영역 / 용지 | `#chat-content-panel .flex-col-reverse.overflow-y-auto` / `… > div` |
| 맨 위 안내문 | `… > div > p:first-child` |
| 내 메시지 | `[id^="chat-message-"] > .mb-4` (내용 없는 턴은 빈 `.mb-4` → `:not(:empty)`) |
| AI 답변 | `[id^="chat-message-"] > [class*="contain:paint"]`, `[data-chat-excerpt="narration" / "dialogue"]` |
| HTML 카드 | `[id^="chat-message-"] .bg-background-markdown\/80` (안에 `article.markdown-body[data-chat-excerpt="text"]`) |
| 상태창 | `[id^="chat-message-"] > .isolate` |
| 버튼줄 | `> [data-chat-content-id]`(위), `> [class*="min-h-[18px]"]`(아래) |
| 입력창 | `[data-chat-composer]`, `form[data-tour="chat-input"]`, `[role="textbox"][contenteditable]`, placeholder는 그 형제 `span[aria-hidden]` |
| 캐릭터 이미지 패널 | `#chat-background-panel`, `#chat-divider-handle` (저장본에는 없었음 → 숨김만 처리, 이미지는 최근 대화 아바타로 대체) |

## 테스트 (개발용)

저장해 둔 케이브덕 채팅 페이지(브라우저 "다른 이름으로 저장" HTML + `_files` 폴더)로 확인합니다.

```bash
python3 -I test/build-test-page.py "저장한페이지.html" "test.html" .
```

`test.html`은 저장한 HTML과 **같은 폴더**에 생깁니다. 노션 스킨 흔적(`data-cvd-*`, `#cvd-*`)과 스크립트를 지우고, `chrome.storage` 스텁 + `content.js` + `theme.css`를 넣으며 주소는 `/talk/…`로 보이게 합니다.

```bash
node test/shoot.js "<저장 폴더>/test.html" <스크린샷 폴더>
```

1440×900, 1024×768, 390×844 스크린샷을 찍고, 상태 표시줄 값과 본문에 남은 색·이탤릭을 출력합니다.

```bash
node test/interact.js "<저장 폴더>/test.html" <스크린샷 폴더> .
```

카드 접기/펼치기, 리본 글자 크기·줄 간격 저장, 옵션별 화면, 파일 이름 형식, 문서 탭 클릭, 보스 키, 끄기(원상 복구), 팝업을 확인합니다.

## 실제 사이트 확인 체크리스트

- [ ] 채팅 화면을 새로고침할 때 원래(다크) 화면이 깜빡이지 않는다
- [ ] **전송**: 입력창에 글을 쓰고 Enter/전송 버튼 → 메시지가 용지에 붙고, 상태 표시줄 글자 수·쪽 수가 늘어난다
- [ ] 답변 생성 중 스트리밍 텍스트도 검정·정자체로 보인다
- [ ] **재생성**: 마지막 메시지 아래 줄(흐린 아이콘)에서 재생성/넘기기 버튼이 눌린다
- [ ] **수정**: 메시지에 마우스를 올려 오른쪽 여백의 연필 아이콘 → 수정 창이 열리고 저장된다
- [ ] 메시지 `⋮` 메뉴가 열리고 항목이 파란 선택색으로 보인다
- [ ] **모델 변경**: 입력창 아래 회색 모델 아이콘 → 모델 선택 창이 열리고 바뀐다
- [ ] 지문(＊), 답변 제안, 더 보기, 메모리, 단축어, 사진 추가 버튼이 동작한다
- [ ] **설정 모달**: 메뉴 줄 오른쪽 ⚙ → 설정 창이 밝은 대화상자 모양으로 열리고 글자가 잘 보인다
- [ ] 메뉴 줄 오른쪽 `<` (뒤로) 버튼이 동작한다
- [ ] 위로 스크롤하면 이전 대화가 더 불러와지고, 상태 표시줄 현재 쪽이 바뀐다
- [ ] 상태창/HTML 카드 캡션을 누르면 펼쳐지고, 캡션을 다시 누르면 접힌다. 카드 안의 `<details>`·버튼도 동작한다
- [ ] 리본 글자 크기 ▲▼·줄 간격, 상태 표시줄 확대 슬라이더가 본문에 바로 반영되고 새로고침 후에도 유지된다
- [ ] **페이지 이동 후 재적용**: 아래 문서 탭으로 다른 대화로 이동 → 제목·탭 강조·문서 제목이 새 캐릭터로 바뀐다
- [ ] 홈/최근 대화 페이지로 나갔다가 다시 채팅으로 들어와도 스킨이 다시 붙는다 (다른 페이지는 원래 화면)
- [ ] 팝업에서 설정을 바꾸면 열린 탭에 바로 반영된다
- [ ] 팝업에서 스킨을 끄면 원래 화면·탭 제목·파비콘으로 완전히 돌아온다
- [ ] Alt+Q 보스 화면이 덮였다 걷힌다 (탭 제목도 바뀜)
- [ ] 창 폭을 768px 아래로 줄이면 제목줄 + 용지 + 상태 표시줄만 남는다
- [ ] 케이브덕을 라이트 모드로 바꿔도 같은 모양이다
